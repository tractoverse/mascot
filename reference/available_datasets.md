# List available datasets

Returns the names of all tractography atlas datasets that can be
accessed via
[`import_bundle()`](https://tractoverse.github.io/mascot/reference/import_bundle.md).

## Usage

``` r
available_datasets()
```

## Value

A character vector of dataset names.

## Examples

``` r
available_datasets()
#> [1] "HCP1065"  "TractSeg"
```
